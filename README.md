# 🍔 Food Delivery System

A full-stack Food Delivery Web Application developed using HTML, CSS, JavaScript, Node.js, Express.js, and MySQL.

## 📌 Project Description

The Food Delivery System is a web-based application that allows users to browse restaurants, view food menus, add food items to a cart, checkout, and place food orders online.

The project uses Node.js and Express.js for the backend and MySQL for database management.

## 🚀 Features

- 👤 User Registration and Login
- 🍽️ Restaurant Listing
- 🍕 Food Menu
- 🖼️ Food and Restaurant Images
- 🛒 Add to Cart
- 💳 Checkout
- 📍 Delivery Address
- 💰 Payment Method
- 📦 Order Placement
- 📋 Order Management
- 🗄️ MySQL Database Integration

## 🛠️ Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MySQL
